# Task Manager (Flask Web Application)

Современный и функциональный веб-менеджер задач, написанный на Python с использованием фреймворка Flask и СУБД SQLite.

🌐 **Живое демо приложения:** [taskmanager205.pythonanywhere.com](https://taskmanager205.pythonanywhere.com/)

---

## Основной функционал

- **Авторизация и безопасность:** Регистрация, вход/выход, хеширование паролей (`Werkzeug`).
- **Управление задачами:** CRUD-операции, описания, приоритеты, дедлайн-трекинг, отметка выполненных.
- **Подзадачи (Чек-листы):** Возможность делить задачу на подпункты.
- **Пользовательские категории:** Создание собственных категорий с цветовыми метками + автосоздание базовых категорий («Личное», «Учёба», «Работа») при регистрации.
- **Pomodoro-таймер:** Настраиваемый интервал времени (минуты и секунды), быстрые пресеты и системные браузерные push-уведомления.
- **Интерфейс и темы:** Адаптивный Bootstrap 5, поддержка тёмной темы и мобильной навигации (FAB + Bottom Bar).
- **Экспорт и импорт:** Сохранение и восстановление задач из JSON и CSV файлов.
- **Поиск и фильтрация:** Регистронезависимый поиск по названию/описанию и пагинация задач.

---

## Стек технологий

- **Backend:** Python 3, Flask, SQLite3, Werkzeug, python-dotenv
- **Frontend:** HTML5, CSS3, JavaScript (ES6), Bootstrap 5, Bootstrap Icons
- **Deployment:** PythonAnywhere, Git / GitHub

## Инструкция по локальному запуску

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/Boarkrat/task-manager.git
   cd task-manager
   ```

2. **Создать и активировать виртуальное окружение:**
   ```bash
   python -m venv venv
   .\venv\Scripts\Activate.ps1   # Для Windows PowerShell
   # source venv/bin/activate    # Для Linux/macOS
   ```

3. **Установить зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустить приложение:**
   ```bash
   python app.py
   ```
   Приложение будет доступно по адресу: `http://127.0.0.1:5000`
